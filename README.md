# Murmur MVP

Murmur is a lightweight personal emotional check-in app designed to help users capture tiny truths, feelings, and meaningful moments in a private, low-friction ritual.

## Features

- Daily prompt to encourage a quick reflection
- Short emotional entry form with mood selection
- Private-by-default storage using browser local storage
- Timeline archive that can be filtered by mood
- Optional sharing to a trusted circle
- Weekly recap summarizing recent emotional patterns

## Run locally

Open `index.html` directly in a browser, or serve the project from any simple static file server.

Example:

```bash
cd murmur-mvp
python3 -m http.server 8000
```

Then open http://localhost:8000

## Notes

- Entries are stored locally in the browser using `localStorage`.
- This MVP focuses on the core habit loop and does not require a backend.
- The app is intentionally private-first and optimized for quick daily use.

## Project structure

- `index.html` – app structure
- `styles.css` – visual styling
- `app.js` – form handling, filters, recap logic, persistence

## Product goals covered

This MVP validates the core loop:

- user sees a daily prompt
- captures a short emotional reflection in under a minute
- saves it privately
- reviews it in a personal timeline
- optionally shares with a trusted circle
- receives a weekly emotional recap
